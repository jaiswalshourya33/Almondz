## 6. Implementation (what changed in the code)

### 6.1 Photographs attached to the three projects

| File | Change |
|---|---|
| `frontend/src/images/projects/` (new folder) | All 21 photographs copied in, renamed to descriptive slugs (`kosi-01-…`, `tuda-01-…`, `wash-01-…`). |
| `frontend/src/data/projects.ts` | Added optional `gallery?: string[]` to the `Project` interface. For the 3 matched projects only, repointed `image`, set `detailImage`, and set `gallery` (every photo from that folder). The 3 previously-used stock imports (`water-treatment-plant.png`, `urban-command-centre.png`, `sector-water.jpg`) are no longer referenced by these projects. All 12 other projects are byte-for-byte unchanged. |
| `frontend/src/components/ProjectDetailsModal.tsx` | **"Site Photographs"** strip: shows only genuinely *extra* photos — filters out any entry equal to `image` (card thumbnail) or `detailImage` (header photo), then caps at **three**. Hidden when none remain. **Header photo:** the photo frame stretches to match the specifications table height (`items-stretch` + `flex-1`); the photo sits inside it via `object-contain` — centred, whole image visible, never cropped or distorted. |

- **Card** (`ProjectCard`) shows `project.image`; the **details modal** header photo shows `project.detailImage ?? project.image`; the new **gallery grid** shows every `project.gallery` entry.
- **Card image framing:** added an optional `imagePosition?: string` to `Project` (a CSS `object-position`, mirroring the existing `Sector.imagePosition`). `ProjectCard`, the modal header photo, and the sector-page carousel apply it when set, so a photo with a tall subject isn't sliced through the middle by the wide card banner. Set so far: `assam-30-ulb-solid-waste-management` → `center 22%` (field-test crew — was showing only legs/ground; now shows faces + the highway worksite); `tripura-state-district-wash-pmu` → `center 42%` (keeps the crew and the sanitary-complex building in frame). Every other project leaves it unset and crops exactly as before.
- `sector-water.jpg` is still used by the Water sector page, so it was left in place. `water-treatment-plant.png` and `urban-command-centre.png` are now unused source assets but were left in the repo (removal is out of scope).
